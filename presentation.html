02 · Chaîne de mesure

Du terrain à la carte

Le système relie les capteurs embarqués, la transmission des relevés et leur consultation sur le web.

01

Mesurer en vol

Les capteurs relèvent le CO₂ et les conditions météo. Le GPS associe une position et une altitude aux données; une carte SD conserve les mesures.

02

Transmettre et enregistrer

La liaison radio envoie les relevés vers le récepteur au sol. Le programme SMARE sur ordinateur les rassemble dans un fichier CSV.

03

Consulter les relevés

Le fichier public alimente cette carte. Les points peuvent être comparés selon la mesure choisie, en vue 2D ou 3D.

03 · Le projet

Observer l’environnement, point par point.

S.M.A.R.E. signifie « Station Météorologique Automatisée de Recherche Environnementale ». Le projet explore une façon mobile de relever des données atmosphériques et de les rendre lisibles sur une carte.

La carte présente uniquement les mesures disponibles dans le fichier partagé. La position et l’altitude permettent de replacer chaque relevé dans son contexte; les valeurs météo complètent l’observation du CO₂.
